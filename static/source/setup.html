Setup · about five minutes
Four commands, then just ask.
1

Install dydt

Adds the dydt command to your computer.

npm install -g dydt-cli
2

Add the skills

Teaches your agent which command to run.

npx skills add dydtai/dydt-skills -g
3

Save your key

Free key from dydt.ai/developers/keys.

dydt config set <your-api-key>
4

Check it works

Prints the live SOL price.

dydt sol-price
{"price_usd": 121.13}

Then restart your agent and ask your first question.
